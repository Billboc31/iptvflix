**Correction requise** : Ajouter une vérification d'existence avant l'insert dans `persistFixedShelvesForSession` :

```typescript
const existing = await db
  .select({ id: shelfInstances.id })

  .where(
    and(

  )
  .limit(1)
if (existing.length > 0) return
```
